# 手机安装与离线打包清单

先在联网时打开生产版，进入「出行」，选择要带走的行程。在「设置 → 离线打包清单」确认缓存时间。iPhone 可用 Safari 的分享菜单选择「添加到主屏幕」，Android 可在 Chrome 菜单选择安装或添加到主屏幕。安装后请从主屏幕打开一次，在这个入口再确认缓存时间，然后开启飞行模式，关闭并重开应用。

离线页显示上次成功读取的行程名称、物品、勾选状态及缓存时间。恢复连接后点「重新连接」即可编辑。个人模式的离线清单按账号隔离，退出登录会清除该账号的缓存。在线设置和离线页都可以点「清除离线缓存」。服务器行程仍保留，下一次成功加载或保存服务器记录会生成新的缓存。系统清理浏览器存储也可能移除缓存。

## 真机试用条件

需要一台实际手机、能从该手机访问的受控 HTTPS 地址，以及手机信任的证书。该地址应提供生产构建的前端、单页路由回退和同源 `/api`，并在代理层限制访问（例如现有的私人 VPN 加访问认证）。电脑的 `127.0.0.1` 在手机上指向手机自己。项目默认服务继续只监听电脑回环地址。真实设备的主屏幕安装、系统存储回收及飞行模式冷启动需要在目标手机上确认。

## 本机自动验证

安装项目依赖和桌面版 Google Chrome 后，从仓库根目录运行 `node --test web/e2e/mobile-pwa.test.mjs`。测试构建生产前端，使用回环地址、合成数据和移动视口，检查应用壳、清单图标、缓存字段、断网读取、清除后重开以及恢复连接。
