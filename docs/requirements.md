# AI 生活管家 · 二级页需求说明

与当前导航、视觉规范一致。今日概览为一级入口，其余为二级页。

## 全局（所有二级页共用）

- 侧栏：今日概览 / 衣橱 / 饮食 / 家居 / 出行 / 支出统计 / 设置
- 顶栏：全局搜索（⌘K）+「今天想安排什么？」AI 入口
- 跨模块：AI 建议可一键采纳；支出流水带模块标签，可跳转支出统计并带筛选

## 1. 衣橱

**目标**  
管好单品与穿搭，按天气/场合给出可执行建议，并沉淀买衣与护理花销。

**核心对象**  
单品、穿搭方案、穿着记录、购买/护理账单

**功能需求**

- 单品库：增删改、分类（上衣/裤装/裙装/外套/鞋包）、标签（季节/颜色/场合）、穿着次数
- 筛选与排序：分类胶囊、添加时间/穿着频次
- 穿搭集：保存、套用、收藏
- 今日穿搭建议：天气联动 + 推荐理由 + 采纳/换一换
- 本模块花销卡片：本月衣类支出，点击进支出统计（筛「衣」）

**AI**  
根据天气、日历场合、库存推荐穿搭；提示久未穿着单品；买衣前可对照衣橱查重

**关键状态**  
空衣橱引导导入/拍照；无天气时降级为场合推荐

## 2. 饮食

**目标**  
记餐与热量目标可追踪，食谱可复用，外卖/买菜花销可统计。

**核心对象**  
餐次记录、食谱、营养目标、饮食账单

**功能需求**

- 今日记录：早/午/晚/加餐时间线，热量与三大营养素
- 目标：日热量与蛋白质/碳水/脂肪进度
- 食谱库：检索、标签（减脂/快手等）、一键加入今日餐次
- 添加/编辑餐次、份量
- 本周摄入趋势
- 本模块花销卡片：筛「食」

**AI**  
按缺口补餐建议；结合食谱推荐；提示外卖偏高时增加自炊

**关键状态**  
未设目标先引导设置；无记录时空态 + 快捷添加

---

## 3. 家居

**目标**  
看清设备状态，一键切场景，异常可处理，能耗与耗材花销可归到「住」。

**核心对象**  
设备、房间、场景模式、告警、住家账单

**功能需求**

- 全局状态：正常/异常摘要、在线设备数
- 场景：回家 / 离家 / 睡眠 / 影院（可扩展）
- 设备卡片：开关、关键参数（温度/亮度等）、房间归属
- 按房间筛选：客厅 / 卧室 / 厨房等
- 异常与提醒：滤芯、离线、低电量等，分级展示
- 本模块花销卡片：水电、滤芯、家电采购等，筛「住」

**AI**  
节能建议（如调温）；出行前联动「离家」场景；耗材到期提醒并估算花费

**关键状态**  
无设备时空态引导绑定；设备离线保留最后状态并标红

---

## 4. 出行

**目标**  
行程可管、票务与清单不漏，出发前联动衣/食/住，费用归「行」。

**核心对象**  
行程、票务/酒店订单、行程节点、行李清单、出行账单

**功能需求**

- 即将出行列表：状态（进行中/即将开始）、交通方式
- 行程详情：时间线（出发/酒店/会议/返程等）
- 票务与酒店状态卡
- 行李清单：进度、勾选、模板
- 路线/地点预览（可后置）
- 新建行程 / 导入订单 / 模板
- 本模块花销卡片：筛「行」

**AI**  
出行准备包：穿搭 + 关家电/离家 + 备餐/附近就餐；生成完整方案

**关键状态**  
无行程引导创建；缺票务时清单与建议仍可用

---

## 5. 支出统计

**目标**  
按衣食住行看清花销与预算，流水可追溯，并给出省钱动作。

**核心对象**  
账单流水、模块分类、月预算、模块预算

**功能需求**

- KPI：本月总支出、环比、预算剩余/总预算、整体进度
- 四模块金额与占比卡片（衣/食/住/行）
- 可视化：本月占比（环图）+ 近 6 个月趋势
- 分模块预算条
- 流水列表：模块标签、金额、日期、商户；支持按模块/时间筛
- 记一笔 / 导入账单（可后置）
- AI 省钱建议（可跳转对应模块动作）

**分类口径**  
见 [spending-taxonomy.md](./spending-taxonomy.md)

**关键状态**  
无流水空态 + 记一笔；未设预算先展示支出再引导设预算
