# 视觉与导航规范

## 全局导航（固定）

顺序：

1. 今日概览
2. 衣橱
3. 饮食
4. 家居
5. 出行
6. 支出统计
7. 设置

底部展示当前用户（示例：星宇）。当前页在侧栏用青绿高亮。

## 顶栏（固定）

- 搜索占位：`搜索衣橱、食谱、设备或行程…`（快捷键 ⌘K）
- 右侧 AI 入口：`今天想安排什么？`

## 颜色

| Token | 值 | 用途 |
|-------|-----|------|
| Primary | `#0D9488` | 主按钮、选中态、AI 强调 |
| Page bg | `#F8FAFC` | 页面背景 |
| Card | `#FFFFFF` | 卡片 |
| Text primary | `#0F172A` | 主文案 |
| Text secondary | `#64748B` | 次要信息 |

## 组件习惯

- 卡片：白底、约 12px 圆角、轻阴影
- 筛选：胶囊标签
- 主操作：实心青绿按钮
- AI 区块：星火图标 + 可一键「采纳」
- 状态：色点 + 短文案

## 跨模块原则

- AI 建议可一键采纳
- 支出流水带模块标签（衣/食/住/行），可跳转支出统计并带筛选
- 各业务页可放「本月本模块花销」小卡片，点击进入支出统计对应筛选
