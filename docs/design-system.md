# 视觉与导航规范

## 全局导航（固定）

顺序：

1. 今日概览
2. 衣橱
3. 饮食
4. 家居
5. 出行
6. 支出统计
7. 设置

底部展示当前用户（示例：星宇）。当前页在侧栏用青绿高亮。

## 顶栏（固定）

- 搜索占位：`搜索衣橱、食谱、设备或行程…`（快捷键 ⌘K）
- 右侧 AI 入口：`今天想安排什么？`

## 颜色

| Token | 值 | 用途 |
|-------|-----|------|
| Primary | `#0D9488` | 主按钮、选中态、AI 强调 |
| Page bg | `#F8FAFC` | 页面背景 |
| Card | `#FFFFFF` | 卡片 |
| Text primary | `#0F172A` | 主文案 |
| Text secondary | `#64748B` | 次要信息 |

## 组件习惯

- 卡片：白底、约 12px 圆角、轻阴影
- 筛选：胶囊标签
- 主操作：实心青绿按钮
- AI 区块：星火图标 + 可一键「采纳」
- 状态：色点 + 短文案

## 跨模块原则

- AI 建议可一键采纳
- 支出流水带模块标签（衣/食/住/行），可跳转支出统计并带筛选
- 各业务页可放「本月本模块花销」小卡片，点击进入支出统计对应筛选

## 移动端（≤ 860px）

- 底部固定五项导航：今日、生活、AI 安排、账本、我的。生活打开底部面板，进入衣橱、饮食、家居、出行；账本与我的分别复用支出统计和设置。
- 手机界面采用奶白底、森林绿主色和圆角卡片。首页依次呈现生活安排入口、两列模块摘要、AI 建议与账本。桌面保留侧栏和各模块主题。
- 衣橱使用两列卡片；分类可以横向滑动；新增和编辑表单从底部打开。主要触控区域至少 44px，输入字号至少 16px，并保留手机安全区。
- 页面切换回到顶部；弹层限制焦点和背景滚动，支持 Escape 关闭并归还焦点。
- 当前交付为响应式 Web 界面。启动 `web` 的开发服务后，手机与电脑在同一局域网时，可通过电脑的局域网地址加端口 `1117` 访问；后端功能仍需要 `server` 服务。
