# 视觉与导航规范

## 桌面导航

侧栏顺序如下。

1. 今日概览
2. 衣橱
3. 饮食
4. 家居
5. 出行
6. 支出统计
7. 设置

侧栏高亮当前页。底部显示当前账号，提供设置入口和个人账号的退出操作。

## 顶栏

- 搜索框可查找衣橱、食谱、设备和行程，支持 ⌘K 或 Ctrl+K 聚焦。
- 桌面右侧的「今天想安排什么？」打开 AI 安排。手机顶栏显示应用名称、账号入口与搜索框。

## 颜色

今日概览与设置使用默认主题。业务页的主题可覆盖这些颜色变量。

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `--primary` | `#34624E` | 主按钮、选中态与 AI 入口 |
| `--bg-page` | `#F7F8F3` | 页面背景 |
| `--bg-card` | `#FFFFFF` | 卡片背景 |
| `--text-main` | `#253C32` | 主要文字 |
| `--text-muted` | `#626F65` | 次要说明 |

## 组件习惯

- 卡片沿用模块主题，默认使用白底与圆角。
- 筛选使用胶囊标签，主操作使用实心按钮。
- AI 区块使用星火图标。可直接保存的建议提供「采纳」按钮，保存成功后更新状态。
- 状态通过文字提示，可配合色点或图标识别。

## 跨模块原则

- 支出流水带衣、食、住、行模块标签。概览与业务页的支出摘要可跳转到相应月份或模块筛选。

## 移动端（≤ 860px）

- 底部固定「今日」「生活」「AI 安排」「账本」「我的」五项。「生活」打开底部面板，可进入衣橱、饮食、家居与出行。「账本」和「我的」分别打开支出统计和设置。
- 今日概览采用奶白底与森林绿主色，依次显示安排与天气入口、两列模块摘要、AI 建议和账本。业务页继续使用各自的主题。
- 衣橱使用两列卡片，分类可横向滑动。弹窗从底部打开。主要触控区域至少 44px，表单输入字号至少 16px，导航与内容为手机安全区留出空间。
- 页面切换后从顶部开始显示。弹窗限制焦点与背景滚动，可用 Escape 关闭并返回原焦点。保存期间保留弹窗，直到写入结果可确认。
- 手机安装、离线打包清单和真机访问条件见[手机安装与离线打包清单](mobile-pwa.md)。
