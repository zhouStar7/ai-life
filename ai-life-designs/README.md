# AI Life · 全新多视觉风格交互设计稿说明

本目录收录了基于现代前沿前端审美标准（Anti-Slop Framework 与高保真交互规范）全新打造的 HTML 交互式设计稿。

除了此前的静态设计切图，本套设计稿为**纯原生单文件、零构建依赖的高保真 HTML 页面**，支持在任意现代浏览器中直接预览、交互和测试。

---

## 🎨 设计方案体系

为了探索不同生活场景最适宜的情感共鸣与交互效率，本次设计稿针对不同模块定制了独立的视觉语言：

| 模块 | 页面文件 | 视觉风格 | 核心设计语言与亮点 |
| :--- | :--- | :--- | :--- |
| **画廊索引** | [`index.html`](index.html) | **Editorial 画廊风** | 极简画廊式索引、大字排版、模块悬停位移、设计理念展示 |
| **衣 · 衣橱** | [`wardrobe.html`](wardrobe.html) | **时尚杂志编辑风** | 象牙白质感、衬线大标、胶囊形态分类、单品搭配与入库交互 |
| **食 · 饮食** | [`diet.html`](diet.html) | **暖阳有机风** | 温暖奶油底色、环形能量平衡图、三餐流水、轻量快捷记餐 |
| **住 · 家居** | [`home.html`](home.html) | **深色中控面板** | 深色面板网格、环境传感器监测、呼吸状态灯、全屋场景模式 |
| **行 · 出行** | [`travel.html`](travel.html) | **瑞士国际主义** | 严谨 12 列网格、黑白高反差、登机牌打孔质感、行程与装箱清单 |
| **支 · 支出** | [`spending.html`](spending.html) | **暗夜极客仪表盘** | JetBrains Mono 等宽字系、单一青色微光强调、分类环比与流水 |

## 🌟 全功能全景工作台原型

在根目录下还包含集成了上述跨域全景联动能力的单文件综合工作台原型：
- 文件：[`ai-life-redesign.html`](ai-life-redesign.html)

  - **全局 Omni Agent 指令条（`⌘K` 唤醒）**。

## 💻 快速预览方式

无需安装 node_modules 或启动开发服务器，直接在浏览器中打开对应 HTML 文件即可：

```bash
# 启动轻量静态服务（可选）
npx serve ai-life-designs
# 或在本地直接双击打开任意 html 文件
```
